# Five Falls Women's Welfare Trust (5Falls)

A modern, accessible, bilingual web application for **Five Falls Women's Welfare Trust** (`5falls.org`), dedicated to reviving dried lakes, desilting ponds, and supporting community development across Tamil Nadu, including Puduthangal Lake in Tambaram.

---

## 🌟 Key Highlights

- **Bilingual Experience**: Full English and Tamil language switching across the entire platform via global `LanguageContext`.
- **Fluid Motion & Design System**: Crafted following modern high-trust design principles with Quarry UI components and smooth Lenis scrolling.
- **Dynamic Field Archive**: Real-time project timeline, high-definition photo/video gallery, before-and-after restorations, and direct UPI/GPay donation modals.
- **Multi-Page Architecture**:
  - `/` — Hero with live odometer counters, spotlight video reels, and interactive ripple animations.
  - `/about` — Trust legacy, mission, and 25-year milestone journey.
  - `/water-bodies` — In-depth exploration of revived lakes and village ponds.
  - `/our-work` — Trust pillars covering lake desilting, women's health, self-help groups, and medical camps.
  - `/updates` — Field dispatches and milestone progress logs.
  - `/gallery` — High-definition photo albums and documentary reels.
  - `/donate` — Transparent donation channels with direct GPay QR and bank NEFT details.
  - `/contact` — Direct hotline, WhatsApp channel, and Tambaram trust office location.

- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: InterVariable / Inter

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ or 20+
- npm, pnpm, or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/sanjayontech/5falls.git

# Navigate to project directory
cd 5falls

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the application.

### Building for Production

```bash
# Create optimized production build
npm run build

# Start production server
npm run start
```
